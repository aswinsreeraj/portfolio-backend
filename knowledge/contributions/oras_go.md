# Open Source Contribution: ORAS Go (OCI Registry as Storage)

- **Repository**: `oras-project/oras-go` (Linux Foundation / CNCF sandbox project)
- **Technology**: Go, OCI image specifications, Docker registries, content-addressable storage
- **Context**: ORAS enables pushing and pulling arbitrary software artifacts (configurations, SBOMs, AI models, binaries) to and from OCI-compliant registries.

## Aswin's Contributions & Experience
- Contributed to the official Go client SDK and CLI utilities.
- Implemented unit and integration test coverage for artifact descriptor manifest validation and layer push operations.
- Investigated and resolved concurrent stream reading edge cases where artifact layer transfers prematurely closed on high-latency registry endpoints.
- Gained hands-on experience navigating large open-source Go repositories, strict review guidelines, and upstream CI workflows.
